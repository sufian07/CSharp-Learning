# C# / .NET API Learning Path

A guided learning journey using two real-world reference repos:

- **`E:\1applications\CleanArchitecture`** — Jason Taylor's Clean Architecture template (single-service, easy to digest).
- **`E:\1applications\eShop`** — Microsoft's official microservices reference app (multi-service, real-world complexity).

## Folder layout

```
CSharp-Learning/
├── lessons/        # Markdown lessons, one file per lesson
├── hands-on/       # Your code for each lesson's exercises
└── README.md
```

## How to use

1. Read `lessons/lesson-01.md`.
2. Do the hands-on exercise in `hands-on/lesson-01-hello-api/`.
3. Ask for the next lesson when you're ready.

You have .NET SDK **10.0.203** installed — verified working.
